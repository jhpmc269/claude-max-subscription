## 付款成功后，这几个坑提前知道

**编码代理会“偷偷”走 API 计费。** 如果你系统里设置过 ANTHROPIC_API_KEY 环境变量，编码代理会优先用这个 key 按 API 费率计费，完全绕开你的订阅额度。升级 Max 之后第一次跑任务前，先检查并清掉这个变量，或者在代理里用 /login 重新登录订阅账号。

**Max 不是无限量。** 5 小时会话上限加每周总上限（部分模型另有单独的周上限），连 Max 20x 也有，只是额度很大。周上限的重置时间绑定在账号的固定时间点上，什么时候开始用、什么时候订阅都不影响，在设置的 Usage 页面能看到下次重置时间。

**撞上限了有三条路。** 等重置；开启按 API 费率计费的额外用量（需要自己在设置里预充值，属于可选功能，不开就不会产生额外扣费）；或者升档。账号里有限额重置（limit reset）权益的话，也可以用它直接把 5 小时或周上限拉满。

**想省钱先改用法。** 官方的用量最佳实践其实很实在：相关任务合并进同一个会话，别每改一行代码就开新对话；发指令前想清楚要什么，减少来回拉扯；利用项目记忆和上下文缓存，别每次都把同样的文件重新贴一遍。这几招能明显推迟撞墙的时间，不少人靠它们在 Pro 上就够用了。

## 常见问题

**Max 有年付吗？**
目前只有月付，官方没开放年付选项。

**官方有折扣码吗？**
没有常规折扣。官方偶尔搞限时活动，通过官方社媒或邮件通知，客服无法单独发放优惠码。第三方渠道（比如本文提到的 Bewild）的立减码是渠道自己的优惠，跟官方促销是两回事。

**Max 5x 和 20x 的功能有区别吗？**
没有。功能列表完全一致，区别只有额度。

**买 Max 送 API 额度吗？**
送，按月发放。注意这是和订阅用量分开的两套体系，API 调用走 Console 计费，具体数额以官方说明为准。

**达到上限后还能继续用吗？**
部分情况下可以降速使用，而不是完全锁死，能不能触发要看当时的负载策略，别指望它。

**取消或降级麻烦吗？**
降级下个周期生效，取消随时可以做，当期权益用到到期为止，没有长期合约绑着你。
